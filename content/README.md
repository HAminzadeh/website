# SakhtYar Flow Content

این پوشه برای محتوای نسخه‌بندی‌شده سایت است.

ساختار پیشنهادی:
- pages/: محتوای صفحات اصلی
- articles/: مقالات آموزشی و تخصصی
- data/: داده‌های ساختاریافته مورد استفاده Seederها

در مرحله بعد، Seeder محتوا به پروژه اضافه می‌شود تا صفحات و مقالات از این پوشه به WordPress محلی و Production همگام شوند.

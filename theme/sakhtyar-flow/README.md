# SakhtYar Flow Theme 0.2.0

نسخه‌ی طراحی حرفه‌ای برای سایت معرفی SakhtYar Flow.

ویژگی‌ها:
- UI مدرن SaaS/PropTech/ConstructionTech
- RTL و فارسی
- طراحی responsive
- Hero حرفه‌ای و Product Mockup
- Persona Sections
- Feature Grid
- Workflow
- Property Score Showcase
- Blog/Academy Cards
- CTA و Footer کامل
- Bootstrap خودکار صفحات اصلی سایت
- آماده اتصال به API و Application

فونت:
قالب از stack زیر استفاده می‌کند و فایل فونت داخل repository قرار نمی‌دهد:
Vazirmatn, IRANSansX, B Nazanin, Segoe UI, Tahoma, Arial

برای نمایش دقیق‌تر Vazirmatn یا IRANSansX می‌توانید بعداً از روش مجاز self-host یا CDN استفاده کنید.
